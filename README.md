# RADIUS Director

RADIUS Director is a configuration management system for FreeRADIUS.

It models RADIUS deployments using reusable Global Objects and tenant-specific configuration, then generates complete, validated FreeRADIUS configuration.

## Project Status

🚧 Early design phase

No production code has been written yet.

Current focus:

- Domain model
- Configuration schema
- Generator architecture
- Production migration planning

## Goals

- Infrastructure as Code
- Reproducible deployments
- Generated configuration
- Vendor neutral
- Standards based
- Operational visibility

## Non-goals

- Replace FreeRADIUS
- Become a billing platform
- Become a captive portal
