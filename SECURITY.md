# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in RADIUS Director, please
do not open a public GitHub issue.

Instead, use GitHub's private vulnerability reporting feature to report the
vulnerability privately.

Please include as much of the following information as possible:

- A description of the vulnerability
- The affected version or commit
- Steps to reproduce the issue
- The potential impact
- Any relevant logs, configuration, or other information needed to reproduce
  the issue

Please do not include passwords, API keys, private certificates, or other
sensitive information in a report unless it is necessary to demonstrate the
vulnerability.

## Supported Versions

RADIUS Director is currently under active development. Security fixes will be
addressed in the current development version and, where appropriate, in
released versions.
